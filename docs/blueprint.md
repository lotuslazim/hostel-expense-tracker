# **App Name**: NourishTrack

## Core Features:

- User Authentication: Secure user accounts with email/password and Google sign-in, ensuring data privacy.
- Daily Meal Logging: Simple interface to log meals (breakfast, lunch, dinner, snacks) with visual indicators for completion.
- Expense Tracking: Record expenses with description, amount, date, and category, with optional receipt photo uploads.
- Item Quantity Tracking: Log quantities of purchased items with unit and cost.
- Missed Day Notifications: Push notifications to remind users to log meals for missed days.
- Date Navigation: Calendar to select any date and log meals, expenses, or item purchases.
- Weekly Summary Report: AI tool generating a summary of meals, expenses, and item purchases.

## Style Guidelines:

- Primary color: Fresh green (#A7D1AB) to represent health and nourishment.
- Background color: Light, desaturated green (#F4F9F4).
- Accent color: Soft yellow (#E8D59A) to highlight key elements and actions.
- Body and headline font: 'PT Sans' for a modern, friendly feel.
- Use clean and intuitive icons representing meals, expenses, and items.
- Mobile-first design with a clean, intuitive interface for easy logging.
- Subtle transitions and animations for user feedback and engagement.
